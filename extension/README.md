# CoGether Cinema Sync Companion Extension

A lightweight, high-performance browser extension that synchronizes playback states (Play, Pause, Seek) across authorized subscriber accounts on **Netflix**, **Prime Video**, **Disney+ / Hotstar**, **Crunchyroll**, and **YouTube**.

---

## 🚀 How to Install in Chrome, Edge, or Brave

1. Open your browser and navigate to:
   - **Chrome**: `chrome://extensions`
   - **Edge**: `edge://extensions`
   - **Brave**: `brave://extensions`
2. Enable **Developer mode** toggle in the top-right corner.
3. Click the **Load unpacked** button.
4. Select the `extension` folder located inside the CoGether application directory:
   ```
   C:\Users\Jeevan Yadav\.gemini\antigravity\scratch\video-call-app\extension
   ```
5. The extension **CoGether — Cinema Sync Companion** is now installed and active!

---

## 🍿 How to Use with Co-Watch

1. Create or join a Co-Watch party room inside CoGether.
2. In the Co-Watch room or Setup Modal, copy your Room Code (e.g. `party-7a2x`).
3. Click the **CoGether Sync** icon in your browser toolbar, enter the Room Code, and click **Connect to Party**.
4. Both you and your friends open the same title on your respective accounts (e.g., *Dune: Part Two* on Max or *Arcane* on Netflix).
5. When anyone plays, pauses, or jumps forward/backward, the extension instantly synchronizes playback across all connected tabs at full native 4K/HDR quality with zero DRM black screen!
